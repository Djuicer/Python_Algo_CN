# 数据压缩

数据压缩随处可见，它能在不过度占用空间的情况下存储数据。
压缩可能损失部分数据，此时称为有损压缩（如 .jpg）；也可能不损失数据，
此时称为无损压缩（如 .png）。

无损压缩主要用于归档，因为它可以在不丢失文件信息的情况下存储数据。
有损压缩则用于传输对质量要求不高的文件，例如社交媒体平台上的图像。
